Coffee Break

A 2D top-down game built in Python: a barista delivers coffee during rush hour while dodging spills and racing the clock.

Type 2D Game
Built with Python

Overview

Coffee Break is a little 2D, top-down game I built using Python. It’s the story of a barista who must deliver coffee during rush hour. The patrons are very messy and keep spilling coffee—and the barista must not step in the coffee to survive. There’s a time limit, and he has to go back to the bar to get a new cup of coffee each time.

I started with a simple prototype, then kept iterating to make a better experience: tuning the frequency of coffee spills and adding sprite-based graphics. I feel like I got it to a pretty good place. I really like the aesthetic and gameplay.

Final version

How It Was Built

I built the game in Python and started with a simple prototype to get the core loop working: move the barista, deliver coffee, avoid spills, return to the bar for a new cup, beat the clock.

Iterations

Spill frequency — Adjusted how often patrons spill coffee so the difficulty felt fair and the level stayed readable.

Sprite-based graphics — Replaced placeholder art with a proper sprite-based look so the game had a clear, cohesive aesthetic.

After those iterations, the game felt solid: the tension of rush hour, the hazard of spreading spills, and the loop of grab cup → deliver → avoid puddles → return to bar all came together. I’m happy with how it plays and how it looks.

Tech Stack

The whole game is built with Python—logic, rendering, and game loop. No external game engine; just code and sprites to get a small, focused 2D top-down experience.
