RC Chopper

I had a helicopter toy when I was a kid and always wanted to control it. This project let me do that—in VR, with a chopper I could fly inside and out.

Type XR / VR Sandbox
Built with Unity + Meta Building Blocks

Overview

I had a helicopter toy when I was a kid and always wanted to control it. RC Chopper is the project that finally let me do that. I grabbed a prebuilt model from Sketchfab, brought it into Unity, and built the controls using Meta Building Blocks. I was able to control the chopper inside and out—and I probably played with it for an hour after I built it. It was really fun.

The experience is simple and satisfying: you’re in VR with a radio-controlled style helicopter. You fly it, land it, and can get right up close or step inside. It’s the childhood fantasy of actually being in the cockpit (or outside it) and having full control.

How It Was Built

The pipeline was straightforward: find a helicopter model that felt right, drop it into Unity, then use Meta Building Blocks to add VR interaction and controls so the chopper responds to your inputs in real time.

Pipeline

1. Sketchfab — Grabbed a prebuilt helicopter model.

2. Unity — Imported the model and set up the scene.

3. Meta Building Blocks — Built the controls so I could fly the chopper and move around it in VR, inside and out.

The result is a controllable RC-style helicopter in VR. You can pilot it, walk around it, and step inside—exactly the kind of toy-helicopter dream that sticks with you from when you were a kid.

Tech Stack

The chopper model came from Sketchfab; Unity handled the scene and logic; Meta Building Blocks provided the VR interaction layer and controls. Together they turned a static model into something you can actually fly and explore.
